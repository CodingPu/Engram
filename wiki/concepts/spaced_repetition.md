# 间隔重复学习法

## 定义

**间隔重复**（Spaced Repetition）是一种基于遗忘曲线的学习方法。核心思想是：**在你即将遗忘某个知识点时，再次复习它，从而大幅提升长期记忆**。

## 历史背景

1885 年，德国心理学家 Hermann Ebbinghaus 通过实验发现了 **遗忘曲线**（Forgetting Curve）：

- 学习后 **1 小时**：保留 50%
- 学习后 **1 天**：保留 30%
- 学习后 **1 周**：保留 20%

这意味着，如果不及时复习，大部分信息会被遗忘。

## 原理

### 遗忘曲线

```
记忆强度
    |
100%|████
    |   ███
 75%|     ███
    |        ███
 50%|           ███
    |              ███
 25%|                 ██
    |                    ██
  0%|__________ 时间 ___________
    1h   1d    1w    1m    1y
```

当记忆强度降到某个临界点（约 50%）时，复习可以立即恢复到 100%，并且**下次遗忘的速度会变慢**。

### 复习间隔的增长

每次成功复习后，下次需要复习的时间间隔会增长：

| 复习次数 | 推荐间隔 | 说明 |
|---------|--------|------|
| 第 1 次 | 1 天 | 第一次复习要尽早 |
| 第 2 次 | 3 天 | 间隔逐步增长 |
| 第 3 次 | 1 周 | 记忆逐步稳定 |
| 第 4 次 | 2 周 | 进入长期记忆 |
| 第 5 次 | 1 月 | 接近永久记忆 |

## 学习效果对比

研究表明，间隔重复比其他方法效果好得多：

| 方法 | 保留率（1 月后） | 学习效率 |
|------|----------------|--------|
| 被动阅读 | ~10% | ⭐ |
| 划线标记 | ~15% | ⭐ |
| 笔记整理 | ~30% | ⭐⭐ |
| **间隔重复** | **70%+** | ⭐⭐⭐⭐ |
| 生成性学习 | 80%+ | ⭐⭐⭐⭐⭐ |

## 现代算法

### SM-2（1987）

最早的自适应间隔重复算法，被 Anki 采用：

```
if answer == "easy":
    EF = EF + 0.1
elif answer == "hard":
    EF = EF - 0.2

interval = interval * EF
```

**优点：** 简单易实现  
**缺点：** 参数不够精确，效率低

### FSRS（2022）

新一代算法，基于机器学习优化，比 SM-2 高效 30%+。

详见 [FSRS 算法](fsrs_algorithm.md)

## 应用场景

### 适合

- 📚 需要长期记忆的知识（语言、数学公式、历史事件）
- 🧠 需要理解的概念（物理原理、编程算法）
- 💼 职业技能（医学术语、法律条款）

### 不太适合

- ❌ 需要快速决策的知识（临时信息）
- ❌ 实时变化的数据（新闻、股价）

## 最佳实践

1. **及时第一复习** — 学后 1 天内复习，效果最好
2. **主动回忆** — 不是被动看答案，而是自己尝试回忆
3. **多样化练习** — 用不同的题目、角度复习同一概念
4. **监测遗忘** — 用工具（如 FSRS）追踪复习进度
5. **生成性学习** — 结合费曼挑战、讲解等方式，效果更好

## 局限性

- **需要耐心** — 长期坚持才能见效
- **初期枯燥** — 前几次复习可能很重复
- **不能替代理解** — 必须先理解，再反复记忆
- **信息爆炸** — 学习太多不同领域时，复习负担大

## 与 Engram 的结合

Engram 的设计就是基于间隔重复原理：

- 使用 **FSRS 算法** 自动计算最优复习时间
- 通过 **多种活动类型**（费曼、连接、应用）提升学习效果
- 用 **主动推送**（不是你主动打开）降低摩擦，提升坚持率
- 结合 **生成性学习**，超越单纯的"Q/A 卡片"模式
